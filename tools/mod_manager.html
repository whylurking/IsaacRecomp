Mods

Where mods.txt goes
  • Windows and Linux: the mods folder next to the program
  • Android: IsaacRecomp/mods/ in the internal storage
  • Nintendo Switch: sd:/switch/isaac/mods/

Replace the one that is there and start the game: mods are read when it starts.

Start from your current settings

Open the mods.txt from the game's mods folder (or drop it on this page) before you change anything. It also brings any other mods it lists.

Adding or removing mods

Put a mod's .mod file in the mods folder: the game adds it to mods.txt, off. Delete a .mod file to remove that mod; one that came with the game stays deleted.

mods.txt is plain text, so any text editor works too: on = 1 or on = 0 under each [id], and its options below.
