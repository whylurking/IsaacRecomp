      Where customchallenges.txt goes
      • Windows and Linux: the mods folder next to the program
      • Android: IsaacRecomp/mods/ in the internal storage
      • Nintendo Switch: sd:/switch/isaac/mods/

      Replace the one that is there. The game reads it each time the challenge list opens, so there is no need to restart it. Turn on the Challenge Lab mod with mod_manager.html.

      In the game

      Main menu, Challenges: the arrow next to Back opens the Challenge Lab (Wrath of the Lamb and Eternal Edition). Every challenge can be played from the start, and nothing in its runs is saved: no unlocks, statistics or collection.
